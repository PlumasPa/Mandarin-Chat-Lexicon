# 中文聊天语料：按情绪与个人性格分类

本目录对仓库现有五份 Markdown 文档**逐条分类**，并保留仓库根目录的五份原文，不删除、不覆盖原始资料。原文仍是权威来源，分类内容是便于检索、选词、构造不同人物说话风格的辅助视图。

## 两条分类轴

- **情绪**：描述具体语境下的即时状态，如开心、愤怒、疲惫、困惑、安慰等。并非仅凭一句话推断真实心理。
- **个人性格**：描述可作为长期语言习惯的表达倾向，如直率、温柔、理性、幽默；这些条目表示*适用于塑造该表达风格*，不证明某个说话者有此人格特质。
- **通用与多义**：没有足够明确的单一情绪/性格指向，或只是中性说明、日常用语、标点规则的条目。**不强行归类**。

同一条目可同时被收录在情绪与个人性格目录中；各文件中保留原文内容及来源行号，便于核查语境。某些语气词存在多义性，单独列入“语气状态与多义辨析”更合适。分类采用关键词和文档上下文辅助归纳，**不等同逐条人工语义审定**；使用时仍须结合上下文判断。
